# Backend

Технологическая основа: Java 25, Spring Boot, Gradle Wrapper,
PostgreSQL, Spring Data JPA, Flyway, Actuator.

В каталоге есть начальный Java/Spring Boot-каркас и Gradle Wrapper.
Декларации устройств, сценарии и API описаны в [проекте контракта](../../docs/contracts/MVP.md),
который требует совместного review. Реализация предметных API, миграций и
проверенный полный запуск пока не подтверждены.

Сборку и CI настраивать через Wrapper из этого каталога с JDK 25;
Maven в этом проекте не используется. Успех сборки/тестов нужно подтвердить
отдельным прогоном, наличие Wrapper не означает их выполнения.
