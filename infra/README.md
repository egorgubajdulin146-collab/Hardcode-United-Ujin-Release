# Инфраструктура

Здесь будут конфигурации запуска, CI, развёртывания и мониторинга.
Способ запуска, окружение и права deploy пока не определены.

Примеры конфигурации должны содержать только названия переменных и безопасные
значения. Секреты передаются отдельно и не включаются в образы или репозиторий.
